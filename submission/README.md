## Google Drive Submission Structure (Round 2)

Per the official competition guidelines:
> *"Submit a Google Drive folder link ('Anyone with the link can view') containing: Technical Abstract PDF, Proof of Concept & Web Viewer Link, Demonstration Video, Code Repository."*
> *"If your team includes additional links, live web demos, prototype access URLs, or supplementary technical documents inside your Google Drive folder, they must be neatly formatted and presented inside a single organized master PDF or Google Doc."*

Upload the contents of this folder directly to your Google Drive submission directory:

| Filename | Deliverable Type | Description |
|---|---|---|
| **`MASTER_SUBMISSION_DOCUMENT.pdf`** | **Master Links & Supplementary PDF** | Single master PDF consolidating all R2 live demo links, repository, video, pipeline architecture, Kaggle notebooks, R2 evidence benchmarks, and R3 roadmap. |
| **`Technical_Abstract_Topoloka.pdf`** | **Technical Abstract (≤ 5 Pages)** | Formal IEEE/ACM formatted abstract detailing mathematical formulation, capture SOP, SfM + Depth Anything V2 pipeline, POI/navigation stack, and empirical results. |
| **`Proof_of_Concept_Web_Viewer_Link.txt`** | **PoC & Web Viewer Link** | Direct link to the live hosted WebGL twin: [https://sciencebanda09.github.io/topoloka/](https://sciencebanda09.github.io/topoloka/) |
| **`Demonstration_Video_Link.txt`** | **Demonstration Video Link (R2)** | Direct link to the 4:11 1080p MP4 R2 walkthrough: [topoloka_r2_demo.mp4](https://github.com/sciencebanda09/topoloka/releases/download/r2-demo/topoloka_r2_demo.mp4) |
| **`Code_Repository_Link.txt`** | **Code Repository Link** | Link to the open-source GitHub repository with sample data in `test/`: [https://github.com/sciencebanda09/topoloka](https://github.com/sciencebanda09/topoloka) |
| **`MASTER_SUBMISSION_DOCUMENT.md`** | Source Document | Markdown source of the master submission document. |
