## Google Drive Submission Structure (Round 1)

Per the official competition guidelines:
> *"Submit a Round 1 Google Drive folder link ('Anyone with the link can view') containing: Technical Abstract PDF, Proof of Concept & Web Viewer Link, Demonstration Video, Code Repository."*
> *"If your team includes additional links, live web demos, prototype access URLs, or supplementary technical documents inside your Google Drive folder, they must be neatly formatted and presented inside a single organized master PDF or Google Doc (e.g., Additional_Links_and_Prototypes.pdf)."*

Upload the contents of this folder directly to your Google Drive submission directory:

| Filename | Deliverable Type | Description |
|---|---|---|
| **`MASTER_SUBMISSION_DOCUMENT.pdf`** | **Master Links & Supplementary PDF** | Single master PDF consolidating all live demo links, repository, video, pipeline architecture, Kaggle notebooks, and empirical benchmarks per Techfest Page 5 guidelines. |
| **`Technical_Abstract_Topoloka.pdf`** | **Technical Abstract (≤ 5 Pages)** | Formal IEEE/ACM formatted 5-page abstract detailing mathematical formulation, capture SOP, SfM + Depth Anything V2 pipeline, and empirical results. |
| **`Proof_of_Concept_Web_Viewer_Link.txt`** | **PoC & Web Viewer Link** | Direct link to the live hosted WebGL twin: [https://sciencebanda09.github.io/topoloka/](https://sciencebanda09.github.io/topoloka/) |
| **`Demonstration_Video_Link.txt`** | **Demonstration Video Link** | Direct link to the 3:33 minute 1080p MP4 walkthrough: [topoloka_demo.mp4](https://github.com/sciencebanda09/topoloka/releases/download/r1-demo/topoloka_demo.mp4) |
| **`Code_Repository_Link.txt`** | **Code Repository Link** | Link to the open-source GitHub repository with sample data in `test/`: [https://github.com/sciencebanda09/topoloka](https://github.com/sciencebanda09/topoloka) |
| **`MASTER_SUBMISSION_DOCUMENT.md`** | Source Document | Markdown source of the master submission document. |
